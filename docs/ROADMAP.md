# Ark9canvas 进化路线图（Roadmap）

> 本文是插件的演进方向声明：每个条目都回答"为什么值得做"与"DSH 生态里为什么只有它能做"。
> 已完成的能力见 [README](../README.zh-CN.md)。按"下一个版本最可能做"排序。

## 定位一句话

**Ark9canvas 不只是一个生图工作台，而是 DSH 里"图像"这一模态的操作系统**：Agent 是它的首选用户，人类是它的审批者与协作者。所有进化方向都围绕这个定位展开。

---

## A. 与 DSH 深度协同（人无我有的差异化）

### A1. Agent 扩写提示词（Prompt Enhancement）★ 下一个版本首选
生图模型吃提示词的质量远高于人类随手输入。DSH 宿主就有 LLM——插件可以加一个 "AI 扩写" 按钮/工具参数 `enhance: true`：
- 把用户一句话（"画个猫"）经宿主 LLM 扩写成专业提示词（主体/风格/构图/光线/镜头）
- Agent 侧：`ark9_generate_image` 自动先扩写再生成（可关）
- **为什么只有 DSH 能做**：Canvas 类独立应用没有宿主 LLM；这是插件对宿主能力的独占调用

### A2. 记忆驱动的风格偏好（与 dsh-auto-memory 联动）★ 创新
用户说过三次"我要水彩风"——auto-memory 里就有这条偏好。Ark9canvas 读取记忆（或经 memory_recall）：
- 生成时自动附上用户历史偏好的风格约束
- 面板显示"根据你的记忆，已默认应用：水彩、柔和光线"
- **协同故事**：auto-memory 负责记住，Ark9canvas 负责表达——"她记得你怎么画画"

### A3. Agent 图文工作流（配图管线）
`ark9_generate_image` 已经返回路径——下一步让 Agent 能把图"用起来"：
- 新工具 `ark9_embed_image(path, mdFile)`：把图插入 Markdown/README/文档（自动算相对路径）
- 场景：Agent 写完 README → 自动生成 hero 图 → 插入 → 一轮完成
- 多图文档配图：Agent 按章节规划 N 张图 → 批量审批一次 → 批量生成

### A4. 审批策略升级（从"每次批"到"规则批"）
当前审批是"每次"或"从不"的二元。进化为规则引擎：
- 按渠道/按尺寸上限/按张数/按模型配置免审批白名单
- "低质量免审批，高质量要审批"（省钱 + 防滥用双目标）
- 审批请求聚合：Agent 连发 5 张 → 面板合并为一次审批

### A5. 通知升级
有待审批时：浏览器 Notification API 系统通知（面板关闭也能收到）；审批超时前 30s 预警。

## B. 生图能力深化（对齐与超越 Canvas）

### B1. 蒙版编辑（inpainting）
画笔涂抹区域 → `/images/edits` 带 mask。gpt-image 系原生支持，是"局部重绘"的核心。需要：
- 面板内置轻量画布（pointer 事件画 mask，导出黑白 PNG）
- 工具参数 `maskImage`

### B2. 变体与种子
- 对生成结果一键"再来 4 张变体"（以图为参考 + 低强度重绘）
- API 支持 seed 时透传并记录，实现可复现生成

### B3. 模型能力注册表
现在是"模型名以 gpt-image 开头就吸附标准三档"的启发式。进化为**能力注册表**：
```json
{ "gpt-image-2": { "sizes": "standard3", "qualities": ["low","medium","high"], "transparent": true, "maxN": 8 },
  "seedream-4": { "sizes": "budget", "maxMP": 4, "transparent": false, "maxN": 4 } }
```
- 按所选模型动态渲染可用的比例/质量/张数选项（不支持的直接禁用）
- 内置常见模型预设 + 用户可编辑 + 从渠道探测

### B4. 成本仪表盘
API 响应里有 `usage.output_tokens`——按模型单价换算成钱：
- 记录页显示每批成本；设置页显示本月累计、今日额度
- **与审批联动**：预算耗尽自动强制审批模式（防失控的关键安全网）
- 面板顶部常驻"本月已花 ≈ $X"

### B5. 本地模型渠道类型
渠道类型从"OpenAI 兼容"扩展到：
- ComfyUI / SD WebUI API 适配器（本地 GPU、零边际成本）
- 渠道对象加 `kind: 'openai' | 'comfyui' | 'sdwebui'`，生成管线按 kind 分派

### B6. 上采样与后处理
生成后一键 2x 放大（本地 Real-ESRGAN 或 API）；尺寸系统已按预算算 4K，补上真的放大能力。

## C. 工作台体验

### C1. 历史即画布：迭代树
迭代改图现在是一条链（每次以最新为参考）。进化为**版本树**：
- 每次生成记录 parent 批次 → 面板可视化分支树
- 任意节点"从此继续"——回溯到第三版换个方向重画
- 数据已有（logs），差 UI 与 parent 指针

### C2. 对比视图
两张生成结果并排 diff（slider 或并排），选片不再翻记录。

### C3. 拖拽全局
从记录页拖图到聊天输入框/文件管理器（DataTransfer API）；从桌面拖图进参考图（已支持文件选择，补 drag-drop）。

### C4. 提示词生态
- 提示词条目带参数模板（{subject} 占位符，应用时填空）
- 从生成记录一键"收藏这次用的完整参数"为可复用预设
- 社区来源订阅（内建一份精选公开源列表 URL，不含任何版权内容）

## D. 工程与分发

### D1. 密钥安全
API key 明文存 `~/.dsh/ark9-canvas.json`。进化：接入 OS 凭据管理器（Windows Credential Manager / macOS Keychain），json 里只存引用句柄。

### D2. 导出格式
配置导入导出已支持；补"渠道分享格式"（脱敏 key 的单渠道 JSON，社区互换配置）。

### D3. 回归测试
smoke-test 14 项已覆盖协议；补：i18n 快照（两语言 key 完整性校验）、SVG 图标渲染冒烟。

### D4. 应用商店就绪
- 首启向导（对标 auto-memory 的 Welcome Tour）：添加渠道 → 拉模型 → 试生成，三步完成
- 截图素材（用插件自己生成的界面宣传图，吃自己的狗粮）

## 优先级建议（下一版本 0.5.0）

| 优先 | 项 | 理由 |
|---|---|---|
| ★★★ | A1 提示词扩写 | DSH 独占能力，一次调用体验跃升 |
| ★★★ | B4 成本仪表盘 | 与审批门控共同构成"花钱安全网"，市场差异化 |
| ★★ | B3 能力注册表 | 手动填模型自由后，按模型禁用无效选项是自然补全 |
| ★★ | A4 审批规则 | 用户反馈"每次批"太频；白名单是留存的钥匙 |
| ★ | A2 记忆联动 | 品牌故事最强，但依赖 auto-memory 接口稳定 |
